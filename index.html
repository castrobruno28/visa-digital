Proteção dos dados de demonstração

Backup e restauração

Exporte os registros locais para um arquivo JSON ou restaure um backup criado pelo VISA Digital.

Atenção: este recurso é para dados fictícios de demonstração. O arquivo pode incluir dados de usuários e senhas demonstrativas armazenadas no navegador. Guarde-o em local seguro e não inclua dados pessoais ou sigilosos reais. O backup não substitui uma solução oficial, centralizada e protegida.

Exportar backup

Arquivo JSON

Inclui estabelecimentos, inspeções, providências, processos sanitários, documentos, usuários gerenciados e auditoria salvos neste navegador.

Restaurar backup

Substitui os dados locais

Selecione um arquivo JSON exportado pelo VISA Digital. A restauração substitui os dados atuais deste navegador e recarrega o sistema.

O que fazer para não perder os dados

1. Baixe o backup
Faça isso depois de alterações importantes.
2. Guarde uma cópia em local seguro
Por exemplo, uma pasta protegida no computador e uma cópia adicional autorizada.
3. Teste a restauração com dados fictícios
A restauração substitui os registros locais existentes; faça um backup antes de restaurar outro arquivo.
