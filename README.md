VISA Digital — Sistema de Gestão da Vigilância Sanitária

Protótipo de sistema desenvolvido para demonstrar possibilidades de organização e controle das atividades da Vigilância Sanitária, reunindo funcionalidades de cadastro, planejamento, acompanhamento e consulta em uma única interface.

Sobre o projeto

O VISA Digital surgiu da observação de necessidades presentes na rotina de trabalho da Vigilância Sanitária. A proposta é explorar como uma ferramenta digital pode facilitar a organização das informações, o acompanhamento das atividades e a consulta aos registros do setor.

O projeto foi desenvolvido por mim como um protótipo funcional e também faz parte do meu portfólio de tecnologia, com foco em desenvolvimento web e, futuramente, em testes de software e QA Manual.

Importante: este projeto é demonstrativo. Não representa um sistema oficialmente implantado ou homologado pela Prefeitura.

Funcionalidades

- Cadastro e consulta de estabelecimentos.
- Planejamento e acompanhamento de inspeções.
- Registro e acompanhamento de processos sanitários.
- Organização de providências e informações relacionadas.
- Alertas para apoiar o acompanhamento das atividades.
- Geração e exportação de relatórios.
- Consulta de informações organizadas em dossiê digital.
- Recursos demonstrativos de backup e restauração.

A disponibilidade e o comportamento de cada recurso devem ser verificados na versão executada do protótipo.

Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilos e apresentação visual.
- JavaScript — funcionalidades e interações.

O protótipo está concentrado no arquivo `index.html`.

Como executar

1. Acesse o repositório e baixe ou clone o projeto.
2. Localize o arquivo `index.html`.
3. Abra o arquivo em um navegador atualizado.
4. Utilize as credenciais demonstrativas documentadas no arquivo de instruções do projeto, quando aplicável.

Não é necessário presumir a existência de servidor ou banco de dados para executar a versão local descrita aqui.

Limitações do protótipo

- Os dados são armazenados localmente no navegador.
- Não há banco de dados compartilhado entre usuários.
- O protótipo não substitui sistemas oficiais da Administração Pública.
- Não possui fluxo administrativo oficial nem assinatura digital.
- Não deve ser utilizado para armazenar dados pessoais, sigilosos ou reais de estabelecimentos.
